The problem

Autonomy stops at the checkout page.

Agents can plan, browse and call tools on their own — but the moment they need to buy something, they hit credit cards, API keys and human approval loops built for people, not machines.

How it works

Four steps. No humans.

Request

Agent calls a paid endpoint.

402

Server replies Payment Required with a price.

Pay

Agent settles on Tempo in any stablecoin.

Retry

Proof attached, real response returned.

Why Tempo

A chain built for machine payments.

Any-stablecoin gas

Pay with whatever you hold — Tempo's enshrined AMM handles conversion.

Sub-second finality

Pay-then-retry feels synchronous to the calling agent.

Payment lanes & memos

Each settlement carries endpoint and agent metadata for analytics.

How Spigot works

The problem

Agents can act autonomously but can't pay without a human in the loop.

The protocol

Request → 402 Payment Required → pay on Tempo (any stablecoin) → retry with proof → response.

Quickstart

npm install @spigot/middleware mppx viem

app.get("/api/premium-data", spigot.charge({ amount: "0.01" }), handler);

Agent side

const res = await mppx.fetch("https://api.example.com/api/premium-data");

Stack

Tempo (chain) · Solidity · Node/Express · MCP tool · Next.js dashboard
